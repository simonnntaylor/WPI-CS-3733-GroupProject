# API Design

The frontend and backend communicate through a RESTful API.

```
/resourceName
  GET or POST
    Payload-to-aws-if-present
    200:
       Payload-out-on-success
    400:
       Payload-out-on-failure
```

## Login Organization

```
/login
  POST
  { "user": "string", "password": "string" }
    200:
        { "token": "unique-auth-token", "user": "string", "accountType": "string" }
    400:
        { "error": "user does not exist" }
        { "error": "invalid user/password combo" }
```

`accountType` can be one of the following: `organization`, `donationCenter`, `admin`.
The view and functionality of the frontend will be determined by the `accountType` returned in the login response.

## Change Password

```
/changePassword
  POST
  { "user": "string", "oldPassword": "string", "newPassword": "string" }
    200:
        { "message": "password changed successfully" }
    400:
        { "error": "user does not exist" }
        { "error": "invalid user/password combo" }
        { "error": "new password cannot be empty" }
        { "error": "new password cannot" }
```
